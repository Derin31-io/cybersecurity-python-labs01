# Завдання 1

У `task1.py` реалізовано:

- клас `User`;
- клас `Admin`, який успадковує `User`;
- клас `Session`;
- `AuditRecord` з використанням `@dataclass`;
- клас `AuditLog`;
- клас `UserAccount`.

Для зберігання пароля використовується
`hashlib.pbkdf2_hmac()` з випадковою сіллю.
Перевірка пароля виконується через `hmac.compare_digest()`.

Для `email` використовується `@property` та перевірка формату
за допомогою регулярного виразу.

# Завдання 2

## Варіант 4

### Призначення

Утиліта аналізує файл `auth.log` та виявляє можливі спроби
SSH brute-force.

Використовуються:

- `re` — для розбору рядків журналу;
- `datetime` — для роботи з часом;
- `collections.defaultdict` — для групування невдалих спроб;
- `argparse` — для параметрів командного рядка;
- `logging` — для повідомлень та попереджень;
- `json` — для формування звіту.

### Що аналізується

Утиліта знаходить події:

```text
Accepted password
Failed password
```

та визначає:

- час події;
- ім'я користувача;
- IP-адресу;
- тип події.

Після цього аналізуються невдалі спроби входу з однієї IP-адреси
у заданому часовому вікні.

Якщо кількість невдалих спроб перевищує встановлений поріг,
IP-адреса додається до рекомендованого blocklist.

---

## Запуск

Базова команда:

```powershell
python -m labs.lab02.task2 --auth-log labs/lab02/data/auth.log
```

Запуск через `main.py`:

```powershell
python -m labs.lab02.main analyze --auth-log labs/lab02/data/auth.log
```

Запуск із власними параметрами:

```powershell
python -m labs.lab02.main analyze `
    --auth-log labs/lab02/data/auth.log `
    --threshold 5 `
    --window-min 5 `
    --output-json labs/lab02/data/blocklist_ips.json
```

---

## Параметри CLI

### `--auth-log`

Шлях до файлу `auth.log`.

Приклад:

```text
--auth-log labs/lab02/data/auth.log
```

### `--threshold`

Кількість невдалих спроб, після перевищення якої
IP-адреса вважається підозрілою.

Значення за замовчуванням:

```text
5
```

### `--window-min`

Кількість хвилин, протягом яких підраховуються невдалі спроби.

Значення за замовчуванням:

```text
5
```

### `--output-json`

Шлях до JSON-звіту.

Значення за замовчуванням:

```text
labs/lab02/data/blocklist_ips.json
```

## Приклад результату

Для тестового файлу `auth.log` утиліта виявляє підозрілу IP-адресу:

```text
203.0.113.77
```

Результат виводиться в консоль:

```text
=== Detected Bruteforce Attacks ===
[ALERT] Bruteforce Detected! IP: 203.0.113.77
```

Рекомендований blocklist:

```text
=== Recommended Blocklist (IPs) ===
203.0.113.77
```

JSON-звіт зберігається у:

```text
labs/lab02/data/blocklist_ips.json
```

Програма обробляє:

- відсутній файл журналу;
- помилки читання файлу;

- неприпустимий `--window-min`.

Для помилок командного рядка використовується `argparse`,
для повідомлень та тривог — `logging`.
